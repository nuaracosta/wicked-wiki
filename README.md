🧹 **Wicked Wiki**
A fan wiki dedicated to the world of Wicked — the beloved Broadway musical and its story of Oz, magic, and unlikely friendship. Built as a school project using HTML and CSS.

📖 **About**
This project is a multi-page static website that explores the characters, locations, songs, and magical lore of Wicked. Each topic has its own dedicated page, all connected through a shared navigation and consistent styling.
